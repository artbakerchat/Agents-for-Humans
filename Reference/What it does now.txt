People usually add Cloudflare to a Bedrock-backed website for specific edge features:

Global CDN & Caching: If you have static assets (images, CSS, HTML) that you want served blazing fast globally before hitting your origin server.

Security & DDoS Protection (WAF): Cloudflare protects your site from botnets, scraping, and volumetric DDoS attacks, which is useful if your AI endpoint is public and vulnerable to API quota draining or abuse.

Cloudflare Workers: If you want to use Cloudflare's serverless edge network to host your TypeScript logic instead of a traditional server, though running Node-heavy SDKs like Strands inside a pure Cloudflare Worker can sometimes require specific configuration (since Cloudflare Workers run on V8 isolates rather than standard Node.js).
